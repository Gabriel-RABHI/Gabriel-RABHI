The project is called Ghost Body Object (GBO). Its name reflects the technical foundations that mitigate the effects of the memory wall, reduce garbage collection (GC) overhead, and lower memory consumption in high-performance distributed systems.

Although I am not a mathematician, I have a strong intuition for what is computationally possible and enjoy finding creative ways to advance the state of the art.
